# 🔍 Smart Resource Finder

Smart Resource Finder is a Python-based web application that helps developers discover GitHub repositories by topic.

## ✨ Features
- Search GitHub repositories by topic.
- Sort projects by stars or forks.
- View repository descriptions.
- Check stars and forks.
- Open repositories directly on GitHub.

## 🛠️ Technologies Used
- Python
- Streamlit
- Requests
- GitHub Search API

## 🚀 How to Run

1. Clone the repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   py -m streamlit run app.py

## 👩‍💻 Project Purpose
This project was created to practice Python, API integration, and web application development.
